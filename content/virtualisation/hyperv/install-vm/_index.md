## Installation

Après avoir lancer le **Gestionnaire Hyper-V**, dans le panneau latéral situé à droite sous **Actions**, sélectionner `Nouveau > Ordinateur virtuel`.

![](/images/virtualisation/hyperv/cover-hyperv-install-vm.png)
